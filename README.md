💬 Aplikasi Klasifikasi Sentimen TokopediaAplikasi berbasis web interaktif menggunakan Streamlit untuk melakukan analisis sentimen pada ulasan atau komentar Tokopedia. Aplikasi ini mengintegrasikan model NLP IndoBERT (AznurOde21/indo-sentimen-tokopedia) dari Hugging Face untuk mengklasifikasikan ulasan ke dalam kategori Positif atau Negatif.✨ Fitur Utama📥 Klasifikasi ManualInput ulasan/komentar secara langsung melalui form teks.Menampilkan hasil prediksi sentimen beserta skor probabilitas tiap label.📁 Klasifikasi File CSVUnggah file .csv yang berisi kolom comment.Mengklasifikasikan seluruh dataset secara otomatis.Menampilkan Distribusi Sentimen (diagram batang).Menampilkan WordCloud dari kata-kata yang paling sering muncul setelah normalisasi teks.Menampilkan 10 Kata Terpenting berdasarkan bobot TF-IDF.Ekspor hasil klasifikasi ke file CSV baru.🔸 Scraping Review TokopediaAmbil ulasan produk secara langsung dengan memasukkan URL halaman produk Tokopedia.Klasifikasi otomatis dari ulasan hasil scraping.Menampilkan visualisasi data (Distribusi Sentimen & WordCloud) dan opsi unduh CSV.🛠️ Prasyarat & Instalasi1. Clone RepositoriBashgit clone https://github.com/username/repository-name.git
cd repository-name

🚀 Cara Menjalankan AplikasiJalankan perintah berikut di terminal:Bashstreamlit run app.py
Setelah itu, aplikasi akan otomatis terbuka di browser Anda pada alamat http://localhost:8501.📁 Format File CSV InputUntuk fitur Klasifikasi File CSV, pastikan file CSV Anda memiliki setidaknya satu kolom bernama comment.Contoh isi CSV:commentBarang bagus banget, respon penjual cepat!Pengiriman lama, dusnya penyok.Mantaaap, sesuai deskripsi.🔬 Arsitektur Teks & Model NLPModel: Pre-trained Transformer Model AznurOde21/indo-sentimen-tokopedia (Fine-tuned IndoBERT).Text Preprocessing:Case folding (mengubah ke huruf kecil).Cleaning karakter non-alphabet & repetisi karakter.Normalisasi kata slang (misal: "mantaaap" $\rightarrow$ "mantap").Pengeliminasian Stopwords Bahasa Indonesia.📝 Catatan Tambahan (Scraping)Catatan: Fitur scraping menggunakan parser BeautifulSoup & requests untuk mengambil tag div[data-testid="lblItemUlasan"]. Struktur HTML Tokopedia dapat berubah sewaktu-waktu. Jika scraping tidak menghasilkan ulasan, periksa kembali selektor HTML atau penanganan proteksi bot dari Tokopedia.
